# YieldShield Stellar

Native Soroban proof of split-risk protection on Stellar testnet. Funded TESTUSD vault-receipt exposure, explicitly issued TESTUSD backing, two exit choices and a first-loss reserve sponsor. No real funds, yield-bearing XLM, guaranteed protection or protocol-token launch.

The implementation and public testnet evidence are being built in separate commits. See [architecture and token decisions](docs/ARCHITECTURE.md). This code and documentation are AI-assisted and unaudited.
